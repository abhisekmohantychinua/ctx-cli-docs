# Guides

CTX workflows describe common situations that occur while working on a project
and show how CTX can be used as part of that work.

These guides are not command references. They focus on what you are trying to
accomplish and the CTX actions that help you get there.

## Daily Work

Use CTX throughout a normal period of development, from starting a session to
reviewing your current work and stopping for the day.

[Read the Daily Work guide](./daily-work)

## Task Execution

Use CTX to organize development work, track the task you are currently working
on, and preserve the state of unfinished or blocked work.

[Read the Task Execution guide](./task-execution)

## Knowledge Capture

Capture useful information while development is happening, including
observations, failed attempts, issues, and decisions.

[Read the Knowledge Capture guide](./knowledge-capture)

## AI-Assisted Development

Use the same project context while working with AI agents so that development
can continue across sessions without losing the state of the work.

[Read the AI-Assisted Development guide](./ai-assisted-development)

## Project Review

Review the current state and history of a project to understand unfinished
work, recent activity, and decisions made during development.

[Read the Project Review guide](./project-review)
