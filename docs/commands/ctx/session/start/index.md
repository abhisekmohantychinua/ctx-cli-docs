# ctx session start

Start a new project session.

## Start (`st`)

### Options

| options | shorthand | required | description |
| --- | --- | --- | --- |
| --end | -e | | End the active session before starting the new session. |
| --notes | -n | | Notes describing this session. |
| --help | -h | | Show this help message and exit. |
| --version | -V | | Print version information and exit. |

## What it does

Starts a new project session and returns its generated identifier.

The session records when the work started and can include notes describing the purpose or focus of the session.

## When to use it

Use `ctx session start` when beginning a new period of work on the project.

Use `--notes` when you want to record what you are working on or the purpose of the session.

## How it works

Only one session can be active at a time.

When an active session already exists, the command stops without creating a new session. Use `--end` to end the active session and start the new one in the same command.

The session identifier is generated by CTX and uses the `S` prefix followed by the next identifier.

Session notes can be provided directly with `--notes=<notes>` or interactively with `--notes`.

The session creation time is recorded when the new session is started.

## Examples

### Start a session

```cmd
ctx session start
```

Starts a new session and returns its identifier.

### Start a session with notes

```cmd
ctx session start --notes="Working on payment retry test."
```

Starts a new session with the provided notes.

### Enter session notes interactively

```cmd
ctx session start --notes
```

Prompts for the session notes before starting the session.

### End the active session and start a new one

```cmd
ctx session start --end
```

Ends the active session and immediately starts a new one.

### End the active session and start a new one with notes

```cmd
ctx session start --end --notes="Working on payment retry test."
```

Ends the active session and starts a new session with the specified notes.
