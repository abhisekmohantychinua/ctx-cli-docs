# Advanced

CTX stays simple for everyday work, while its advanced capabilities give you more control, richer context, and a closer view of project activity when you need them.

These capabilities support work that goes beyond the basic execution workflow, including larger projects, historical context, AI-assisted development, and detailed project analysis.

## Advanced Capabilities

### [Instruction](./instruction/)

Learn how CTX gives AI agents a stable way to access project context. The generated instruction explains how to use CTX, while the execution context remains dynamic and lives in CTX itself. This keeps project guidance separate from sessions, tasks, logs, and decisions, allowing the agent to retrieve the current state when needed.

### [Views](./views/)

Learn how CTX presents project records through different views. This section covers the views available for sessions, tasks, logs, and decisions, including the task-specific list and tree views. Each view supports a different level of detail and a different way of understanding project execution.

### [Querying](./querying/)

Learn how to search and retrieve project records through CTX's query system. Querying supports field-based filtering, expressions, pagination, and sorting across sessions, tasks, logs, and decisions. It is intended for users who need more precise access to project history than the standard views provide.

### [Reference](./reference/)

Learn how logs and decisions can be connected to the execution context they belong to. References allow logs and decisions to point to a specific session or task, making otherwise independent records easier to understand and retrieve as part of a larger piece of work.

## Working With Advanced Features

Advanced features are independent. You do not need to learn or use all of them to use CTX effectively. Use them when a particular need arises:

- **Instruction** — Provide project rules to an AI agent.
- **Views** — Display project records in different formats.
- **Querying** — Find specific records.
- **Reference** — Associate a log or decision with a task or session.

Together, these capabilities add depth to CTX without making the everyday workflow more complicated.
