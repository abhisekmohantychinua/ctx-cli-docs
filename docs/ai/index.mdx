# AI

CTX includes features that make the project's execution context easier for AI agents to understand and use.

These features do not change how CTX works as a CLI. They provide a way for CTX to work with the AI tools already used in a project.

## Instructions

CTX can generate an instruction file that explains to an AI agent how to use CTX and access the project's execution context.

The generated instructions are designed for supported AI environments, and you can also write them to a custom location when your setup requires it.

[<Icon icon="mdi:book-open-page-variant" className="inline-icon" /> Learn about Instructions ](../advanced/instruction)

## Skills

CTX provides reusable skills for AI agents.

A skill gives an AI agent focused guidance for a particular way of working with CTX. Unlike general documentation, a skill is intended to be consumed by an AI environment as part of its working capabilities.

[<Icon icon="mdi:github" className="inline-icon" /> Visit CTX CLI Skills repository](https://github.com/abhisekmohantychinua/ctx-cli-skills).

## What's Available

CTX currently provides two ways to work with AI agents:

- **Instructions** — Generate CTX instructions for supported AI environments or a custom project path.
- **Skills** — Provide reusable CTX workflows for AI agents.

This section can grow as CTX adds more ways for AI agents to work with project context.
