# AI

CTX provides features that make its project context easier for AI agents to understand and use.

These features do not change how CTX works as a CLI. Instead, they help connect CTX with the AI tools already used in a project.

## Instructions

CTX can generate an instruction file that teaches an AI agent how to use CTX and retrieve the project's execution context.

The generated instruction is designed to work with supported AI environments and can also be written to a custom location.

[<Icon icon="mdi:book-open-page-variant" className="inline-icon" /> Learn about Instructions ](../advanced/instruction)

## Skills

CTX provides reusable skills for AI agents.

A skill gives an AI agent focused guidance for working with CTX in a particular way. Unlike general documentation, a skill is designed to be consumed by an AI environment as part of its working capabilities.

[<Icon icon="mdi:github" className="inline-icon" /> Visit CTX CLI Skills repository](https://github.com/abhisekmohantychinua/ctx-cli-skills).

## What's Available

CTX currently provides:

- **Instructions** - Generate CTX instructions for supported AI environments or a custom project path.
- **Skills** - Provide reusable CTX workflows for AI agents.

This section will grow as CTX adds more ways to work with AI agents.
